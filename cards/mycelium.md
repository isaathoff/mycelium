Trees communicate with each other—but not directly. Like a tin can telephone, they need a string connecting them, with a can on each end.

That "string" is a fungus: not the cap we see above ground, but a network of thread-like cells underground that connects root to root.

Through this network—the mycelium—trees exchange water, nutrients, and signals.
